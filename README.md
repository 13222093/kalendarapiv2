# KalenderApi v1.1

KalenderApi for NASA Space Apps 2026, challenge *Harmonization of MODIS and VIIRS Hot Spots*.

- **Pre-registration:** [`PREREGISTRATION.md`](PREREGISTRATION.md), registered as GitHub Release `prereg-v1`.
- **Origin:** a copy, made on 14 November 2026, of the team's v1.0 app, which is a separate project.
- **Based on Fire Harmony:** that app is a modified version of Fire Harmony (Apache License 2.0). Credits and the list of changes are in `NOTICE.md`.

## Run

```bash
npm ci
npm run dev
```
